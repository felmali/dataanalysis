# Data Analysis Portfolio

A collection of data analysis projects developed using SQL, Excel, Power BI, and Python. The portfolio covers data preparation, exploratory analysis, customer segmentation, KPI development, and dashboard reporting.

## Skills & Tools

- SQL
- Power BI
- Excel
- Python
- Data Analysis
- Data Visualization
- KPI Development
- Customer Segmentation
- Dashboard Reporting

## Featured Projects

### 1. Online Retail — RFM Customer Segmentation

**Tools:** SQL  
**Focus:** Customer analytics, segmentation, KPI development

Analyzed customer purchasing behavior using Recency, Frequency, and Monetary (RFM) metrics. Customers were scored and segmented based on purchasing patterns.

**Key techniques:**
- CTEs
- Window functions
- NTILE()
- Aggregations
- Customer-level metrics
- CASE-based segmentation

### 2. HR Employee Attrition Dashboard

**Tools:** Power BI  
**Focus:** HR analytics, KPI development, dashboard reporting

Developed a Power BI dashboard to analyze employee attrition and identify patterns across employee-related factors.

### 3. FLO Customer & Sales Analysis

**Tools:** SQL  
**Focus:** Sales performance, customer analysis, channel analysis

Analyzed customer and sales data to examine revenue, orders, customer counts, sales channels, product categories, and purchasing patterns.

### 4. Student Mental Health Analysis

**Tools:** Power BI, SQL  
**Focus:** Data analysis, KPI development, dashboard visualization

Analyzed relationships between depression and factors such as academic/work pressure, satisfaction, financial stress, and working hours. Developed KPIs and visualizations to communicate key findings.
